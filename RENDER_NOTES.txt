ملاحظات رفع Render (تجربة):
1. ارفع المشروع على GitHub (محتويات مجلد centerly أو المستودع والجذر = manage.py)
2. New Web Service
3. Build Command:
   pip install -r requirements.txt
4. Start Command:
   python manage.py migrate && gunicorn config.wsgi:application
5. Environment Variables:
   SECRET_KEY=...
   DEBUG=0
   WHATSAPP_ENABLED=0
6. بعد أول دخول أنشئ Superuser من Shell في Render:
   python manage.py createsuperuser
